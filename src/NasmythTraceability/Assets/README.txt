Brand assets
============

Drop the Nasmyth logo here as:

    nasmyth-logo.png        (preferred - transparent or white background)
    nasmyth-logo.jpg        (also accepted)

On the next build it is compiled into the app and BrandLogo shows it in the
header automatically, replacing the built-in vector fallback. No code change
needed - the file name is what matters.

Recommended: a horizontal logo around 480 x 200 px or larger.
