Brand assets
============

logo.png    Company logo shown in the header of the main window (top left).

It is compiled into the app on the next build. To change the logo, replace
logo.png with another PNG of the same name and rebuild - no code change needed.
The logo is shown on a white plate, so a white or transparent background suits it.

Recommended: a horizontal logo about 2:1 wide, 480 x 240 px or larger, so it
stays sharp on high-DPI screens.
